Exponents and Square Roots

Squaring a number means multiplying it by itself: 52 = 5 × 5 = 25. A square root undoes a square: √25 = 5.

Useful facts

  • A squared number is never negative: (−4)2 = 16. Squaring is how statistics gets rid of minus signs.
  • √(9 + 16) = √25 = 5. The root applies to the whole sum. It is not √9 + √16 = 7.
  • 0.52 = 0.25. Squaring a number between 0 and 1 makes it smaller.
  • Squaring a score and then taking the square root gets you back where you started (for positive numbers).

Where you will see them

Later in the course you will meet measures of spread that are built from squared distances, and a second measure made by taking the square root of the first so the answer is back in the original units. You do not need the names yet. You need to be comfortable squaring and taking roots.

Small and large numbers in output

Software sometimes prints very small numbers in scientific notation such as 1.2E-4, which means 1.2 × 10−4 = 0.00012. Likewise, 0.000 in software output means “smaller than 0.0005”, not exactly zero.

Key Takeaways

  • Squaring multiplies a number by itself; a square root undoes it.
  • A squared value is never negative.
  • The root applies to the whole expression under it: √(9 + 16) = 5, not 7.
  • Software may print very small numbers in scientific notation.
