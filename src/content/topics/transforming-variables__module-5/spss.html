6.3 Transforming and Recoding Variables

It's common in data analysis to find that one of your variables isn't quite in the format you need. You might want to convert a continuous variable into categories, or you might need to apply a mathematical transformation. This section covers how to handle these pragmatic data manipulation tasks.

Terminology: Variable Transformation

  • Transformation – Applying a mathematical function to create a new variable from an old one
  • Recoding – Changing the values of a variable according to specific rules
  • Centering – Subtracting a constant (usually the mean) to shift the scale
  • Collapsing – Combining multiple categories or ranges into fewer categories

6.3.1 Creating a transformed variable

To create a computed variable in SPSS:

  1. Choose Transform → Compute Variable…
  2. Type a name for the new variable in Target Variable (letters, numbers, underscores; no spaces)
  3. Enter a formula in Numeric Expression
  4. Click OK. The new column appears at the right end of Data View

Example: Centering a Likert scale
If you have a 1-7 Likert scale and want to center it so the midpoint is 0, name the target likert_centred and enter: 

likert_raw - 4

This transforms the scale from 1-7 to -3 to +3, making the neutral point 0. Remember to set the new variable's Measure and add a Label in Variable View.

6.3.2 Using the ABS() function for opinion strength

Sometimes you want to separate the strength of an opinion from its direction. The ABS() function (absolute value) is perfect for this. With target likert_strength: 

ABS(likert_centred)

This creates a variable showing how far from neutral each response is, regardless of positive or negative direction.

6.3.3 Conditional transformations

To compute a value only for the rows that meet a condition, click the If… button in the Compute Variable dialog, choose Include if case satisfies condition, and type a logical expression. Rows that fail the condition are left missing in the new variable.

Example: Creating a pass/fail variable. Make a numeric variable passed in two steps.

  1. Compute passed = 0 (for everyone).
  2. Compute passed = 1 with If… set to Score >= 60. Click OK and confirm that you want to change the existing variable.

Then give passed value labels (0 = Fail, 1 = Pass) and set Measure to Nominal. A shortcut for yes/no variables is to compute the logical expression itself: target passed, expression Score >= 60. This stores 1 for true and 0 for false.

Key Points: Conditional rules

  • The If dialog uses the same operators as Select Cases: =, ~=, <, >, AND, OR, NOT.
  • Rows that do not meet the condition keep their old value (if the variable already exists) or become missing (if it is new).
  • For more than two categories, use Recode (next section), which is easier to read than several stacked conditions.

6.3.4 Collapsing a variable into categories

Often you'll want to group continuous data into a smaller number of discrete categories. For example, collapsing age into young/adult/older categories can make analysis and interpretation easier. In SPSS use Transform → Recode into Different Variables…:

  1. Move Age into the box, type a name such as age_group under Output Variable, and click Change
  2. Click Old and New Values…
  3. Choose Range, LOWEST through value, type 20, and under New Value type 1, then Add
  4. Choose Range, type 21 through 40, new value 2, Add
  5. Choose Range, value through HIGHEST, type 41, new value 3, Add
  6. Click Continue, then OK
  7. In Variable View, give age_group value labels (1 = Young, 2 = Adult, 3 = Older) and set Measure to Ordinal

Always choose Recode into Different Variables, not Into Same Variables. The "Same" option overwrites your original data, and Undo is not always available later. SPSS also has Transform → Visual Binning…, which draws a histogram so you can place the cut points by eye.

However, be cautious: collapsing continuous data into categories loses information. Only do this when the resulting categories are meaningful for your research question.

Critical Point: When to Collapse Variables

Consider these factors before collapsing continuous variables:

  • Loss of information – Categorizing throws away detail and can reduce statistical power
  • Meaningful categories – Ensure your categories make theoretical sense, not just computational convenience
  • Alternative analyses – Often you can analyze continuous data directly (e.g., regression instead of ANOVA)
  • Assumption violations – Categorized data may violate assumptions (e.g., normality) that the original data satisfied

6.3.5 Repeating a transformation on several variables

When you need the same transformation for several variables (for example, many questionnaire items), you do not have to retype the dialog each time. Build the first one with Compute Variable, but click Paste instead of OK. The Syntax Editor then holds a line such as: 

COMPUTE item1_strength = ABS(item1 - 4).
EXECUTE.

Copy that line once for each variable, change the names, and choose Run → All. Pasting syntax is also the best way to keep a record of exactly which transformations you made.

Check every new variable with Descriptives (is the minimum and maximum what you expect?) and a quick Frequencies table for any recoded categories.
