Summation Notation

The capital Greek letter Σ (sigma) means “add up everything that follows.” It is the most common symbol in statistics.

Reading Σ

Take the scores x = 2, 5, 8, 1 (so n = 4).

  • Σx = 2 + 5 + 8 + 1 = 16. This is the sum of the scores.
  • Σx2 = 22 + 52 + 82 + 12 = 4 + 25 + 64 + 1 = 94. Square each score first, then add.
  • (Σx)2 = 162 = 256. Add first, then square.

Notice that Σx2 (94) and (Σx)2 (256) are different. The brackets decide which step comes first.

Summing a calculation

The sign can sit in front of a whole expression. To work out Σ(x − 4)2 for the same scores, do the calculation for each score first, then add:

So Σ(x − 4)2 = 30. Setting the work out in columns like this keeps long sums from going wrong.

Subscripts

Sometimes you will see xi or x1, x2, and so on. The little number just names which score you mean: x3 is the third score, 8. Where you see Σxi with limits, it means add every score from the first to the last.

Key Takeaways

  • Σ means add up everything that follows.
  • Σx² (square, then add) is not the same as (Σx)² (add, then square).
  • For a sum of a calculation, do the calculation on each score first, then add the results.
