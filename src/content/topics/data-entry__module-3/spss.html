Entering and Importing Data in SPSS

The rule for building a data file

In SPSS you define the variables first (Variable View) and enter the scores second (Data View). Doing it in that order means every column already has the right type, labels, and measurement level when the numbers go in.

Step 1: Start a new file

Choose File → New → Data. You get an empty Data View.

Step 2: Define each variable in Variable View

Click the Variable View tab. Each row is one variable. For each of the five:

  1. Type the name in the Name column. Names must start with a letter and cannot contain spaces (use SleepHours or Sleep_Hours).
  2. Leave Type as Numeric. (Group will be numeric too; see step 3.)
  3. Set Decimals to 0 for whole numbers.
  4. Type a longer description in Label (for example Hours of sleep last night). Labels appear in your output, so they make tables readable.
  5. Set Measure: ID is Nominal, Group is Nominal, Age and SleepHours are Scale, and Stress (a total score) is Scale.

Step 3: Code the Group variable

Enter groups as numbers and attach labels: in the Values cell for Group, click the … button, add 1 = Control, click Add, then add 2 = Treatment and click Add. Click OK.

Step 4: Type the scores in Data View

Return to the Data View tab and type down each column (Group as 1 or 2). Press Tab to move right, Enter to move down. Use View → Value Labels to see Control and Treatment instead of 1 and 2.

Step 5: Save

Choose File → Save As…, pick your course folder, name the file (for example sleep_practice), and make sure Save as type is SPSS Statistics (*.sav).

Opening a data file

To open a file you have been given, choose File → Open → Data… and select it. If you do not see your file, change Files of type at the bottom of the dialog (it may be set to .sav only).

Importing Excel files

  1. Choose File → Open → Data….
  2. Set Files of type to Excel (*.xls, *.xlsx, *.xlsm) and select your file.
  3. In the box that opens, keep Read variable names from the first row of data ticked if row 1 has column headings.
  4. Pick the worksheet if there is more than one, then click OK.

Clean the spreadsheet first: headings in row 1, one case per row, no merged cells, no blank rows, and no totals row at the bottom.

Importing CSV and text files

  1. Choose File → Open → Data… and set Files of type to Text (*.txt, *.dat, *.csv, *.tab) (or choose File → Import Data → CSV Data).
  2. SPSS starts the Text Import Wizard. Work through its steps:
    • Predefined format: No.
    • How are your variables arranged? Delimited.
    • Are variable names at the top of your file? Yes (line 1).
    • Which delimiter? Comma for a CSV file.
    • Check the preview, then keep clicking Next and finish with Finish.

Imported data arrives with SPSS's guesses for Type and Measure. Always open Variable View afterward and correct them.

Check your data after any import

Five minutes here prevents wrong answers later.

  1. Look at it. Scroll through Data View. Does it have the number of rows you expect? Are the columns what you expect?
  2. Check Variable View. Fix Type and Measure, add Labels, Values, and Missing codes.
  3. Run a frequency check. Choose Analyze → Descriptive Statistics → Frequencies…, move a categorical variable into Variable(s), and click OK. Look for impossible or misspelled categories.
  4. Check the range. Choose Analyze → Descriptive Statistics → Descriptives…, move your numeric variables over, and click OK. Look at Minimum and Maximum. An age of 220 or a rating of 55 on a 1–5 scale is a typo.

Saving and exporting

  • Your data: File → Save (or Save As) as a .sav file. This keeps all your Variable View settings.
  • A copy for other programs: File → Save As… and choose a different Save as type such as Excel or comma-delimited (*.csv). Other programs will not see value labels unless you keep the box for labels ticked.
  • Your results: click in the Viewer, then File → Export… and choose Word, Excel, or PDF. Save the Viewer itself as .spv if you want to reopen it in SPSS.

When something goes wrong

When something goes wrong
ProblemLikely cause and fix
All the data landed in one columnWrong delimiter in the Text Import Wizard. Reopen the file and pick Comma (or Tab).
The first row of data became variable names, or the headings became dataThe "variable names at top" answer was reversed. Reopen and change it.
Group shows 1 and 2 instead of wordsTurn on View → Value Labels, or add value labels in Variable View.
A mean looks far too largeA missing-value code such as 99 is being counted as a score. Declare it in the Missing column.
A numeric column imported as text (left-aligned)Something non-numeric is in the column (a stray space, "N/A"). Fix it in the source file and reimport.
You cannot find the file to openChange Files of type in the Open dialog to match the file's extension.

Key Takeaways

  • Define variables in Variable View first, then enter scores in Data View.
  • Open Excel and CSV files with File → Open → Data and change Files of type; check the delimiter and header-row choices.
  • After any import, fix Type and Measure, then run Frequencies and Descriptives to catch errors.
  • Save data as .sav; export output separately through File → Export.
