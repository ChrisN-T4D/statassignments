The SPSS Interface

Overview

IBM SPSS Statistics works with three windows and one idea that runs through all of them: you point and click through menus and dialog boxes, and SPSS writes the results into a separate output window. Once you know which window you are in, most of the confusion about SPSS goes away.

Menu names below match recent versions of SPSS. If your copy looks slightly different, check the Help menu or ask in the class forum. The steps are the same; a label may be reworded.

The three windows

1. The Data Editor (where your data lives)

The Data Editor has two tabs at the bottom left. You will switch between them constantly.

  • Data View: a spreadsheet. Each row is a case (usually one participant) and each column is a variable.
  • Variable View: the settings sheet. Each row describes one variable (its name, type, labels, and measurement level).

Tip: double-click a column heading in Data View to jump straight to that variable's row in Variable View.

2. The Viewer (where results appear)

Every analysis you run and every chart you build is written to the Viewer (also called the Output window). It opens automatically the first time you run something.

  • The left panel is an outline. Click an entry to jump to that table or chart.
  • The right panel holds the tables and charts themselves.
  • Output is not saved with your data. Save it separately as an .spv file, or export it (File → Export) to Word, Excel, or PDF.
  • Each new analysis is added below the last one, so the Viewer fills up. Delete anything you do not need by selecting it in the outline and pressing Delete.

3. The Syntax Editor (optional, for repeatability)

Behind every dialog box SPSS runs a short text command. The Syntax Editor lets you see, save, and rerun those commands. Open a blank one with File → New → Syntax. In most dialogs you can click Paste instead of OK to copy the command into the Syntax Editor without running it. You do not need syntax for this course unless an assignment says so, but pasting syntax is a good way to keep a record of what you did.

The menu bar

Menus in the Data Editor, in the order you will meet them in this course:

  • File: open, save, import, and export data and output.
  • Edit: undo, copy and paste, and Options (default folders and display settings).
  • View: show or hide value labels, gridlines, and the status bar.
  • Data: sort cases, select cases, split a file by group, weight cases.
  • Transform: Compute Variable, Recode, and other ways to create or change variables.
  • Analyze: every statistical procedure. The submenus you will use most are Descriptive Statistics, Compare Means, Correlate, Regression, and Nonparametric Tests.
  • Graphs: the Chart Builder for histograms, bar charts, boxplots, and scatterplots.
  • Utilities, Extensions, Window, Help: housekeeping, add-ons, switching windows, and the built-in help.

How dialog boxes work

Almost every Analyze or Graphs menu item opens a dialog box built the same way:

  1. Your variables are listed on the left.
  2. Select a variable, then click the blue arrow to move it into the box on the right (such as Variable(s), Dependent List, or Factor).
  3. Buttons on the right (Statistics…, Options…, Charts…, Plots…) open a second dialog. Make your choices there and click Continue.
  4. Click OK to run it, or Paste to copy the syntax instead.

If a dialog remembers your last choices from an earlier analysis, click Reset before you start so old settings do not carry over.

Set a default folder (do this once)

Choose Edit → Options… → File Locations. Under Data files, choose Specified folder and browse to the folder where you keep your course files. From then on, File → Open and File → Save start in that folder instead of somewhere random.

Habits that save you grief

  • Save your .sav data file often (Ctrl+S on Windows, Cmd+S on Mac). SPSS does not autosave your data.
  • Save your data under a new name (File → Save As) before you recode or compute anything, so your original file stays untouched.
  • Check which window you are in before you save or close. The title bar says Data Editor, Viewer, or Syntax Editor.
  • Use the Window menu to switch between open windows.
  • Read the red or yellow notes SPSS writes into the Viewer. They often tell you why a result looks wrong.

Key Takeaways

  • Data lives in the Data Editor (Data View for values, Variable View for settings); results appear in the Viewer.
  • Data (.sav), output (.spv), and syntax (.sps) are saved separately.
  • Every analysis follows the same dialog pattern: move variables right with the arrow, set options, click OK.
  • Use Paste to record the syntax of what you did, and save under a new name before changing your data.
