Variable Types and Measurement Levels in SPSS

Two settings, two different questions

Every variable in SPSS has a Type and a Measure. They sound alike, but they answer different questions:

  • Type asks: what kind of thing is stored in this column? (numbers, text, dates)
  • Measure asks: what does the variable mean? (categories, ordered ranks, or amounts). This is the scale of measurement from Module 2.

Both are set in Variable View. Open it with the tab at the bottom left of the Data Editor.

Type: what is stored

Click the cell in the Type column, then the small … button, to open the Variable Type dialog.

TypeUse it forExample
NumericNumbers you can calculate with, and numeric codes for groupsAge = 21; Group = 1
StringText, such as names or open-ended answers. You cannot take a mean of a string."Amy"
DateDates and times in a chosen format03/27/1972
Dollar / Custom currencyMoney values$12,300

Width and Decimals only control how many characters and decimal places SPSS displays. Setting Decimals to 0 for a whole-number count (such as number of friends) keeps tables tidy. It does not round the stored value.

Measure: Nominal, Ordinal, or Scale

SPSS has three measurement choices. They map onto the four scales you learned in Module 2:

SPSS MeasureModule 2 scaleExamples
NominalNominalMajor, group (control or treatment), yes/no
OrdinalOrdinalClass rank, "strongly disagree" to "strongly agree"
ScaleInterval and ratioTemperature in °C, reaction time, number of friends, income

SPSS has no separate setting for interval versus ratio. Both are called Scale.

SPSS makes a guess when you enter or import data. Numeric columns default to Scale and text columns to Nominal. The guess is often wrong, so check the Measure column for every variable. A column of group codes (1, 2, 3) is numeric, but it is Nominal, not Scale.

In dialog boxes, the variable list shows a small icon next to each name: a ruler for Scale, a bar chart for Ordinal, and three circles for Nominal. If an icon looks wrong, fix the Measure setting.

Coding categories with value labels

Groups are usually stored as numbers (1, 2, 3) because many SPSS procedures need numbers. To keep the numbers readable, give each one a value label:

  1. In Variable View, click the cell in the Values column for your variable, then the … button.
  2. Type the code in Value (for example 1) and its meaning in Label (for example Control).
  3. Click Add. Repeat for every code (2 = Treatment).
  4. Click OK, then set Measure to Nominal.

Switch back to Data View and choose View → Value Labels to show the words instead of the numbers. This changes only what you see, not the stored values.

Watch out: SPSS will happily compute the mean of a column of group codes. The answer (a mean of 1.5, say) is meaningless. Measure and value labels are how you and SPSS keep track of which numbers are amounts and which are just names.

Missing values

A blank numeric cell is stored as system-missing and shown as a dot. If you used a code such as 99 for "no answer", tell SPSS so it is left out of calculations:

  1. In Variable View, click the Missing cell, then the … button.
  2. Choose Discrete missing values and type 99 (you can list up to three codes).
  3. Click OK.

If you skip this step, SPSS treats 99 as a real score and every mean and standard deviation will be wrong.

A note on rating scales

A single 1–5 agreement item is technically ordinal. In practice, researchers often treat the total of many such items as Scale. Your instructor will tell you which to use in an assignment. Whichever you choose, set the Measure to match so SPSS offers the right charts and options.

Key Takeaways

  • Type is what is stored (Numeric, String, Date); Measure is what it means (Nominal, Ordinal, Scale).
  • SPSS has one Scale setting for both interval and ratio data.
  • Always check the Measure column, because SPSS guesses it.
  • Give group codes value labels, and define missing-value codes such as 99 so they are not analyzed as scores.
