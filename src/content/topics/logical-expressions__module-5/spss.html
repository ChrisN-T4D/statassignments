6.2 Logical Expressions in SPSS

A key concept in data transformations is the idea of a logical value. A logical value is an assertion about whether something is true or false. SPSS evaluates a logical expression to either true or false. When you store the result in a variable with Compute Variable, true is saved as 1 and false as 0.

Terminology: Logical Operators

Logical operators allow you to make comparisons and combine conditions:

Operator Meaning Example Result
= (or EQ) Equal to 2 + 2 = 4 true (1)
~= (or <> or NE) Not equal to 2 + 2 ~= 5 true (1)
< Less than 2 < 3 true (1)
<= Less than or equal 2 <= 2 true (1)
> Greater than 3 > 2 true (1)
>= Greater than or equal 3 >= 3 true (1)
AND (or &) Both conditions true (2=2) AND (3=3) true (1)
OR (or |) At least one condition true (2=2) OR (2=3) true (1)
NOT (or ~) Negates the condition NOT(2=3) true (1)

6.2.1 Assessing mathematical truths

You can see how SPSS judges a statement by saving it in a computed variable. Choose Transform → Compute Variable…, type test in Target Variable, and enter this in Numeric Expression: 

2 + 2 = 4

Click OK. The new column test is filled with 1 (true), because 2 + 2 does indeed equal 4. If you try: 

2 + 2 = 5

you get a column of 0 (false). Logical expressions are the same ones you type into Select Cases → If and into the If button inside Compute Variable.

Critical Point: = does two jobs in SPSS

Many programs use == to test equality. SPSS does not; typing == gives an error. In SPSS:

  • In a Compute Variable dialog, the target name and expression are in separate boxes, so no assignment symbol is needed.
  • In a condition (Select Cases → If, or the If button), a single = means "is equal to".
  • Use ~= (or <>) for "not equal to".

In pasted syntax you will see COMPUTE test = (2 + 2 = 4). The first = assigns; the second tests.

6.2.2 Combining logical operations

You can combine logical operators to create complex conditions:

  • AND – Both conditions must be true
  • OR – At least one condition must be true
  • NOT – Reverses the truth value

Examples: 

(Age >= 18) AND (Age <= 65)       /* true for adults 18-65 */
(Status = "Student") OR (Status = "Faculty")   /* true for students or faculty */
NOT(Score < 50)                    /* true for scores 50 or above */

6.2.3 Applying logical operations to text

Logical operators work with text (strings) as well as numbers. However, SPSS is strict about exact matches:

  • "cat" = "cat" is true
  • "cat" = "CAT" is false (case-sensitive!)
  • " cat" = "cat" is false (a space at the start matters; SPSS ignores spaces at the end of a string)

Key Points: Working with Text

  • Case matters – "Cat", "cat", and "CAT" are all different
  • Spacing matters – Extra spaces make strings different
  • Alphabetical order – You can use < and > with text ("cat" < "dog" is true)
  • Uppercase before lowercase – All uppercase letters come before all lowercase in alphabetical ordering
