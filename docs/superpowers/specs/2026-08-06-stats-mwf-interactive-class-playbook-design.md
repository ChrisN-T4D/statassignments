# PSYC 4213 Statistics — M/W/F interactive class playbook (design)

**Course:** PSYC 4213 Statistics, Fall 2026 in-person Canvas **2405** (aligned to online **3177**)  
**Meeting:** Mon / Wed / Fri, **8:00–8:50** (50 min)  
**Constraint:** Main classroom + **satellite rooms on one shared Zoom** (usually model A); some local turn-and-talk OK; design for **solo Zoomers** as the fallback  
**Content map source:** week/module schedule in `scripts/update-statistics-syllabus-fall2026.py` `SCHEDULE_ROWS` and the M/W/F class map (`cursor-brainstorm` plan `2026-08-06-stats-mwf-canvas-class-map.md`)  
**Goal:** Students want to show up — fun, interactive, hybrid-safe energy at 8am  

**Approach (approved):** Recurring Mon / Wed / Fri **rituals** (not 41 unique full scripts). Light special-day overlays for Week 1, Benchmark weeks, Week 15, Module 8.

---

## 1. Success criteria

- Instructor can open the playbook at ~7:40, pick today’s ritual + prompt stub, and run class without inventing structure.
- Every interactive prompt works for: (1) students in the main room, (2) satellite rooms with 2+, (3) solo Zoomers.
- First 5 minutes always interactive; last 5 minutes always an exit ticket.
- No new tool every week; graded points stay in Canvas / Methods Market — in-class competition is for energy, not grades.

---

## 2. Hard rules (every meeting)

1. Something interactive in the **first 5 minutes**.
2. Every prompt has a **solo-Zoomer path** (Mentimeter / Zoom chat / personal jamovi).
3. Local pairs when possible; satellites pair in-room if 2+; solo Zoomers never wait for a neighbor.
4. Teach to **camera + screen share**, not only the people in front of you.
5. Put the prompt **on the shared screen** (not only said out loud).
6. Collect answers **digitally first**, then call on 1 local + 1 remote voice.
7. Cap pair talk at **90–120 seconds**, then harvest.
8. Competitive light (bragging rights); never shame.

## 3. Default 50-minute skeleton

| Minutes | Block |
|--------:|-------|
| 0–5 | **Open ritual** (poll / claim / “what’s wrong with this?”) |

**Day roles (content weeks)**

| Day | Ritual name | Purpose |
|-----|-------------|---------|
| **Mon** | Hook | Curiosity + why this week matters |
| **Wed** | Concept fight | Peer instruction / spot the mistake / sort |

**Non-content / special weeks** keep the same skeleton; swap the middle block (review fights, LockDown dry-run, catch-up studio).

---

## 4. Hybrid participation playbook

Announce **three lanes** at the start of each activity:

| Lane | Who | What they do |
|------|-----|--------------|
| **Room** | Students with instructor | Turn to neighbor (or triad of 3) |
| **Satellite pair** | 2+ in a remote room | Same prompt, talk in that room (mics muted) |
| **Solo Zoomer** | Alone on Zoom | Same prompt in Mentimeter/chat (or assigned chat buddy) |

**Share-out rule (Fri):** every studio ends with **one visible product** (screenshot, jamovi output, or typed claim) — not “we discussed it.”

**Do not rely on:** walking the aisle as the only check, whiteboard-only demos, paper handouts as the only path.

- No new tool every week.
- No graded in-class clicker points.

## 6. Activity repertoire

### Mon — Hook moves (pick one, ~5–12 min including harvest)

1. **Myth bust** — True/false psych-stats urban legends  
2. **Bad headline** — claim; vote what’s wrong (design / measurement / causation)  
3. **Weird data** — one chart or tiny dataset; “what question is this answering?”  
4. **Would you bet?** — stake imaginary $ before teaching the concept  

### Wed — Concept fight moves

1. **Peer instruction** — hard MC → vote → 90s talk (3 lanes) → revote → reveal  
2. **Spot the flaw** — fake student answer or bad jamovi output  
3. **Sort the pile** — classify (NOIR, IV/DV, graph type) via Mentimeter or shared doc  
4. **Teach-back** — 45-second explanation (local or remote); class rates clarity 1–5  

### Fri — Studio moves

1. **Follow-along build** — same jamovi steps; first correct screenshot in chat = bragging rights  
2. **Bug hunt** — instructor “accidentally” messes a setting; class fixes it  
3. **Methods Market sprint** — ~10 min on one item; share one sticky confusion  
4. **Assignment workshop** — start Canvas task live; exit with next step written down  

**Tone:** short wins over long simulations; always bridge to the week’s Canvas cue in the last ~10 minutes.
