# PSYC 4223 Research Methods — M/W/F concept calendar

**Fall 2026 · Canvas 2406**  
**Meetings:** Mon / Wed / Fri · **12:00–12:50** (50 min)  
**Design:** `docs/superpowers/specs/2026-08-18-psyc4223-mwf-concept-calendar-design.md`

**Goal:** Open today’s week and see 2–4 named concepts from this week’s Methods Market chapter, or a Friday capstone workshop.

The only chapter each week is the Jhangiani Pressbooks chapter in Methods Market. The Canvas holy handbook is an outline of what comes next (Parts / phases) — it names the Friday workshop, not a second textbook.

## How to use this at 11:40

1. Open **Week stubs** for today’s date.
2. Monday / Wednesday: teach the listed concepts (same chapter both days).
3. Friday: capstone workshop only — no new concepts.
4. Bookmarks: Methods Market class URL, Assignment Help, Canvas 2406, this calendar.

No hook / fight / studio. No exit tickets.
