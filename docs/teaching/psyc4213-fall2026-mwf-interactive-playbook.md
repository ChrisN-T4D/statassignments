# PSYC 4213 Statistics — M/W/F interactive class playbook

**Fall 2026 · In-person Canvas 2405** (aligned to online 3177)  
**Meetings:** Mon / Wed / Fri · **8:00–8:50** (50 min)  
**Format:** Main classroom + satellite rooms on **one shared Zoom**  
**Design:** `docs/superpowers/specs/2026-08-06-stats-mwf-interactive-class-playbook-design.md`

**Goal:** Students want to show up. Fun, interactive, hybrid-safe energy at 8am.

---

## How to use this at 7:40

1. Open **Week stubs** for today’s date.  
2. Note the day ritual: **Mon = Hook**, **Wed = Concept fight**, **Fri = Studio** (special weeks override).  
3. Pick one **repertoire card** that matches the stub.  
4. Run the **50-minute skeleton**.  
5. Announce the **three lanes** before any pair talk.  
6. End with a **one-question exit ticket**.

Bookmarks to keep open: Methods Market class URL, Assignment Help, Mentimeter (or Kahoot) presentation, jamovi, this playbook.

---

## Hard rules (every meeting)

1. Something interactive in the **first 5 minutes**.  
2. Every prompt has a **solo-Zoomer path** (Mentimeter / Zoom chat / personal jamovi).  
3. Local pairs when possible; satellites pair in-room if 2+; solo Zoomers never wait for a neighbor.  
4. Teach to **camera + screen share**, not only the people in front of you.  
5. Put the prompt **on the shared screen** (not only said out loud).  
6. Collect answers **digitally first**, then call on **1 local + 1 remote** voice.  
7. Cap pair talk at **90–120 seconds**, then harvest.  
8. Competitive light (bragging rights); never shame.  
9. In-class polls are for energy — **not graded**. Grades stay in Canvas / Methods Market.

## Hybrid: three lanes

Announce this every time you start pair talk:

| Lane | Who | What they do |
|------|-----|--------------|
| **Room** | Students with you | Turn to neighbor (or triad of 3) |
| **Satellite pair** | 2+ in a remote room | Same prompt, talk in that room (mics muted) |
| **Solo Zoomer** | Alone on Zoom | Same prompt in Mentimeter or chat |

**Fri share-out rule:** every studio ends with **one visible product** (screenshot, jamovi output, or typed claim) — not “we discussed it.”

**Do not rely on:** walking the aisle as the only check, whiteboard-only demos, paper-only handouts.

## Repertoire cards

### Mon — Hook moves

#### Myth bust

- **When:** Urban legends, fixed-mindset talk, NHST myths.  
- **Steps:** (1) Show true/false claim on screen. (2) Vote. (3) 90s three-lane talk. (4) Revote optional. (5) Reveal + 60s reframe.  
- **Solo Zoomer:** Same vote in Mentimeter; type one reason in chat.  
- **Harvest:** 1 local + 1 remote; then teach the correct frame.

#### Bad headline

- **When:** Causation, measurement, or lying graphs.  
- **Steps:** (1) Show headline/claim. (2) Vote: what’s wrong (design / measurement / causation / graph). (3) 90s talk. (4) Reveal the clean critique.  
- **Solo Zoomer:** Vote + one-word chat code (D/M/C/G).  
- **Harvest:** Digital first, then two voices.

#### Weird data

- **When:** Central tendency, skew, “what question is this answering?”  
- **Steps:** (1) Show tiny dataset or chart. (2) Poll the best summary or question. (3) Mini-teach from their answers.  
- **Solo Zoomer:** Poll + optional chat.  
- **Harvest:** Show distribution of votes before explaining.

#### Would you bet?

- **When:** Causal language, probability guts, design choice.  
- **Steps:** (1) Pose scenario. (2) Stake imaginary $ on option A/B. (3) Reveal after mini-teach.  
- **Solo Zoomer:** Mentimeter stake.  
- **Harvest:** Celebrate good bets; no shame for wrong ones.

---

### Wed — Concept fight moves

#### Peer instruction

- **When:** Hard conceptual MC (NOIR, p-values, CLT, z, graph choice).  
- **Steps:** (1) Show item. (2) Silent vote. (3) Announce three lanes; 90–120s talk. (4) Revote. (5) Reveal + brief why.  
- **Solo Zoomer:** Vote both times; chat one argument if alone.  
- **Harvest:** Comment on vote shift, not on who was “dumb.”

#### Spot the flaw

- **When:** Bad jamovi settings, bad student write-up, screen-record mistakes.  
- **Steps:** (1) Show flawed artifact. (2) Poll: where is the bug? (3) 90s talk. (4) Fix live on shared screen.  
- **Solo Zoomer:** Poll + typed location of flaw.  
- **Harvest:** First correct chat screenshot/type gets bragging rights.

#### Sort the pile

- **When:** NOIR, IV/DV, graph types, which test.  
- **Steps:** (1) List 4–8 items. (2) Students code category in Mentimeter/chat. (3) Reveal key.  
- **Solo Zoomer:** Type codes (e.g., N/O/I/R).  
- **Harvest:** Correct one contested item together.

#### Teach-back

- **When:** After a dense mini-teach; review weeks.  
- **Steps:** (1) Ask for a 45s explanation (local or remote volunteer). (2) Class rates clarity 1–5. (3) You patch one gap.  
- **Solo Zoomer:** Can volunteer unmute or type the teach-back.  
- **Harvest:** Thank the volunteer; rate the idea, not the person.

---

### Fri — Studio moves

#### Follow-along build

- **When:** jamovi skills (data entry, descriptives, graphs, CIs).  
- **Steps:** (1) Same steps on shared screen. (2) Students mirror. (3) First correct screenshot in chat wins bragging rights.  
- **Solo Zoomer:** Same build; screenshot to chat.  
- **Harvest:** One visible product on screen (yours or a volunteer’s).

#### Bug hunt

- **When:** Measurement levels, filters, wrong graph, wrong variable.  
- **Steps:** (1) You “accidentally” break a setting. (2) Class diagnoses. (3) Someone directs the fix.  
- **Solo Zoomer:** Type the fix step in chat.  
- **Harvest:** Apply fix live; screenshot final state.

#### Methods Market sprint

- **When:** Concept Review or Software Practice day.  
- **Steps:** (1) Open one assigned item together. (2) ~10 min work. (3) Sticky confusion in Mentimeter word cloud or chat.  
- **Solo Zoomer:** Same item in Methods Market.  
- **Harvest:** Address top 1–2 confusions only.

#### Assignment workshop

- **When:** Friday due-soon weeks; Benchmark preview Fridays.  
- **Steps:** (1) Open Canvas task on screen. (2) Start the first move live. (3) Exit ticket = “my next step is ___.”  
- **Solo Zoomer:** Same; type next step.  
- **Harvest:** Collect next steps; clear one blocker.
