Path 1 - Survey Methodology
  Path 1: Survey Methodology (Observational Research)

Best For: Measuring prevalence, attitudes, correlations.
Software: SPSS or Jamovi (Required)
Constraint: Focus on 2 to 3 Core Variables (IV/DV). Use existing, validated measures (no self-drafted questions).

Phase 1: Measure Selection & Review

Search: Find validated psychometric scales for your IV and DV.
Check Reliability: Look for Cronbach's Alpha (α ≥ 0.70).

Phase 2: Variable Mapping

Define Structure: Map scale items to SPSS/Jamovi variables.
Reverse Coding: Define value labels (e.g., 1=Never, 5=Always).

Phase 3: Ethics & IRB

Consent: Include purpose, voluntary nature, and anonymity.
Submission: Submit to IRB with copyright clearance.
Deliverable: IRB Approval Letter.

Phase 4: Sampling & Collection

Target: N≥30N \ge 30N≥30 (Correlation) or N≥100N \ge 100N≥100 (Regression).
Action: Distribute link; Monitor for straight-lining.
Deliverable: Raw Data Export (.CSV).

Phase 5: Data Analysis (SPSS/Jamovi)

Clean: Handle missing values (99/999).
Stat: Descriptive (Frequencies/Means) + Inferential (t-test/ANOVA/Correlation).
Deliverable: Statistical Output PDF.
