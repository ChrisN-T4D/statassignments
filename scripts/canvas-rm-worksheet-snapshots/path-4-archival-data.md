Path 4 - Archival Data
Path 4: Archival/Secondary Data Analysis

Best For: Analyzing trends, secondary data, historical context.
Software: SPSS, Jamovi, R, or Python.
Constraint: Focus on 2 to 3 Core Variables from the Dataset.

Phase 1: Dataset Selection

Source: Public datasets (CDC, Census, etc.).
Feasibility: Check dictionary, access level, and NNN.
Deliverable: Dataset Evaluation Form.

Phase 2: Cleaning & Preparation

Plan: Handle missing values, deduplicate, standardize variable names.
Deliverable: Data Cleaning Plan & Cleaned Dataset.

Phase 3: Ethics & IRB

Status: Usually Exempt (No contact with subjects). - Still Need IRB Approval
Deliverable: IRB Approval Letter

Phase 4: Analysis

Tasks: Trends, Correlation, Regression.
Deliverable: Archival Analysis Report.
